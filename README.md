# Arduino dual-axis solar tracker (PH222, IIT Bombay, Spring 2025)

Course project for PH222: a dual-axis solar tracker that orients a small PV panel towards the brightest direction
using LDR sensors and two servos, logging the panel voltage in real time. The report compared tracked vs. fixed-panel output.

`arduino_lab1_dac_led_driver.ino.txt` is the earlier lab sketch from the same course (DAC-driven LED current control,
reading the op-amp output on A1). The tracker sketch itself is not in this repo yet; the report is available on request.
